# Screenshots

Four images, in this order, referenced from the top level README.

| File | Page | What to capture |
| --- | --- | --- |
| `live-alerts.png` | `/live` | The alert feed with twenty or more rows and the threat intelligence panel filled |
| `models.png` | `/models` | The top of the page: the comparison table and the feature importances |
| `tuning.png` | `/tuning` | All four sweep charts |
| `data.png` | `/data` | The pipeline table and the class balance circles |

How to take them so they look finished:

1. Start the API and the dashboard, then let the replay run for two or three
   minutes at 25 flows per second. A half empty chart reads as a half finished
   project.
2. Use the dark theme, which is the default.
3. Make the browser window wide, at least 1600 pixels, and take the screenshot
   of the page content only, without the address bar.
4. Save as PNG at the names above.
